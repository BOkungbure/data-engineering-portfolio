# 📊 Analytics API

A REST API built with FastAPI that serves business metrics from a SQL database.

## 🎯 Goal
Replace manual Power BI data pulls with a live API endpoint — automating reporting for business stakeholders.

## 🛠️ Stack
- Python
- FastAPI
- PostgreSQL
- Docker
- GitHub Actions (CI/CD)
