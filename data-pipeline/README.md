# 🔧 End-to-End Data Pipeline

An automated ELT pipeline that extracts raw sales data, loads it into PostgreSQL, transforms it using dbt, and schedules everything with Apache Airflow.

## 🛠️ Stack
- Python
- dbt (Data Build Tool)
- Apache Airflow
- PostgreSQL (Neon)
- GitHub Actions (CI/CD)
